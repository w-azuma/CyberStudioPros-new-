# CyberStudioPro

Three.js製、サイバーパンク風の3D DJスタジオ。デッキA/Bにそれぞれ音楽ファイルを読み込み、
実際に音を混ぜたり、EQ・ピッチ・ホットキューを操作できる。

## セットアップ

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + 本番ビルド
```

## 構成

```
src/
  main.ts                     # エントリーポイント。各モジュールを結線してアニメーションループを回す
  types.ts                    # DraggableControl など共通の型
  audio/
    DeckAudioEngine.ts         # デッキ1台分のWeb Audioグラフ(EQ・ボリューム・ピッチ・ホットキュー)
    MixerEngine.ts              # クロスフェーダーでA/Bを混ぜてマスターへ出力
  core/
    SceneManager.ts             # レンダラー・カメラ・ライティング・筐体などの静的な舞台
  components/
    Deck.ts                     # プラッター・ピッチフェーダー・ホットキューパッドの見た目と操作
    Mixer.ts                    # チャンネルフェーダー・クロスフェーダー・EQノブ・VUメーター
    Monitors.ts                 # 上部モニター3枚のキャンバス描画
  interaction/
    InteractionManager.ts       # レイキャストでどのコントロールを掴んだか判定し、
                                 # 以降はポインター移動量(px)でドラッグを処理する
  ui/
    ControlPanel.ts             # 曲の読み込み・再生/一時停止・キュー・シンクのHTMLオーバーレイ
```

設計方針として、「誤操作すると困る操作」(読み込み・再生・キュー・シンク)はHTMLボタンで、
「質感が大事な操作」(EQ・ピッチ・クロスフェード・ホットキュー・スクラッチ)は3Dオブジェクトを
直接ドラッグ/クリックする形にしている。

## 操作方法

| 操作 | 方法 |
| --- | --- |
| 曲の読み込み | 各デッキのファイル入力から選択 |
| 再生/一時停止 | PLAYボタン、またはプラッターをクリック |
| キュー | CUEボタン(再生中に押すとキューポイントへ戻って停止、停止中に押すと現在位置を記録) |
| スクラッチ | プラッターを左右にドラッグ(再生速度が一時的に変化する) |
| ピッチ | デッキ横のフェーダーを上下にドラッグ(±8%) |
| シンク | SYNCボタンで相手デッキのBPMに合わせてピッチを自動調整 |
| ホットキュー | デッキA: キーボード `1`-`8` / デッキB: `Q W E R T Y U I`、またはパッドを直接クリック。`Shift`+押下でクリア |
| ニードルドロップ | トーンアームのヘッドシェルを左右にドラッグ(盤の外周=曲頭、内周寄り=曲の終わり側にシーク) |
| チャンネルボリューム | ミキサー中央のフェーダーを上下にドラッグ |
| クロスフェーダー | 手前のクロスフェーダーを左右にドラッグ |
| EQ / トリム | ミキサーのノブを上下にドラッグ(上段からHigh/Mid/Low/Trim) |
| Color FX(Filter) | EQ列よりさらに奥、オレンジの発光リング付きノブをドラッグ(左=LPF/右=HPFのフィルタースイープ) |
| クロスフェーダーカーブ切替 | クロスフェーダー奥のレバーをクリック(緑=SMOOTH/等パワー、ピンク=SCRATCH/急峻カーブ) |
| Beat FX(Echo) | ミキサー奥のボタンをクリックしてon/off(on時はその時点の平均BPMに同期したディレイがマスターにかかる) |
| カメラ | ドラッグで回転、ホイールでズーム(コントロール操作中は無効化) |

## 機材のモチーフについて

DJ松永(Creepy Nuts)の実使用機材(PIONEER DJ DJM-S11 / TECHNICS SL-1200MK7 / KS DIGITAL
C5-Referenceモニター等)を参考に、以下を追加している。

- ミキサー: DJM-S11の「Sound Color FX」相当のフィルターノブ、Magvel Fader Proのような
  クロスフェーダーカーブ切替(SMOOTH/SCRATCH)、Beat FX(Echo)のon/offボタン、
  マスターリミッターとそのゲインリダクションを示すLED
- デッキ: SL-1200MK7を意識した可動式トーンアーム(ドラッグでニードルドロップ操作が可能)、
  プラッター縁のストロボドット、レコード盤の溝を模したリング、曲名/BPMを表示する
  レーベル部分の液晶風表示
- オーディオエンジン: 曲の先頭60秒程度からエネルギー・オートコリレーションでBPMを
  自動推定(簡易実装、詳細は下記「既知の制約」を参照)
- ブース: KS DIGITAL C5-Referenceを意識した2ウェイ(ツイーター+ウーファー)風の
  スピーカー筐体

## 既知の制約

- BPM自動検出は簡易的なエネルギー・オートコリレーション方式のため、本格的なビート
  検出器ほどの精度はなく、倍/半分のオクターブ違いが起こることがある
- 1つの`AudioContext`をA/B・マスターで共有しているため、ブラウザの自動再生制限により
  最初の操作(ファイル選択やクリック)まで音声コンテキストがsuspended状態になることがある
- Beat FXのディレイタイムはon/off切り替え時点のBPMで一度だけ計算しており、以後の
  ピッチ/シンク操作にはリアルタイム追従しない
- マスターリミッターは常時挿入だが、あくまで簡易的な保護目的でパラメータ調整UIは無い
